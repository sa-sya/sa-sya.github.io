# sasya. — Photography & Visual Creation

GitHub Pages portfolio website for sasya.

## Files
- `index.html` — page structure
- `style.css` — design and responsive layout
- `script.js` — photo lightbox interaction
- `*.jpg` — six image assets used by the site
- `.nojekyll` — disables Jekyll processing on GitHub Pages

## Publish on GitHub Pages
1. Open the `sa-sya/sa-sya.github.io` repository.
2. Choose **Add file → Upload files**.
3. Extract this ZIP first, then upload the files inside the extracted folder (not the enclosing folder).
4. Keep all six JPG files, `index.html`, `style.css`, `script.js`, and `.nojekyll` together in the repository root.
5. Commit the upload. GitHub Pages is configured to publish from `main` and `/(root)`.

The gallery uses a consistent 4:3 frame ratio, a two-column layout on mobile, and more generous spacing. Image paths are relative to the repository root.
