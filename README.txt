【内容】
index.html / style.css / script.js と、表示に必要な写真6枚をまとめています。
トップページは画面いっぱいに写真を表示するフルスクリーン仕様です。

【GitHubへの反映方法】
1. このZIPをiPhoneまたはPCでダウンロードして解凍します。
2. 解凍した中のファイル（index.html、style.css、script.js、.nojekyll、6枚のjpg）をすべて選びます。
3. GitHubの sa-sya/sa-sya.github.io リポジトリの main ブランチ直下で Add file → Upload files を開きます。
4. 解凍したファイルをすべてアップロードします。
5. 既存ファイルと同じ名前のものは置き換え、Commit changes を押します。

重要：ZIPファイルそのものをリポジトリに置くだけではサイトは更新されません。必ず解凍して、中身のファイルをアップロードしてください。
このパッケージはリポジトリ直下に配置する構成です。assets等の別フォルダの中に入れないでください。
GitHub Pagesの公開反映には数分かかる場合があります。
